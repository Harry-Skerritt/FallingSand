# Falling Sand Simulator
### This is a simulation of falling sand written in SFML and C++
It currently uses an image as the sand and slowly builds up the picture as more sand is simulated


## Controls
- **C** - Clears the screen
- **F3** - Shows / Hides the debug info (default on)


## To Install
Download the zip folder, and click the .exe inside /bin
